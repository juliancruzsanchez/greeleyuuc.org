Simple, beautiful Mailchimp signup: [uucg_newsletter]

== Description ==

* Shortcode `[uucg_newsletter]` or `[newsletter_signup]`
* Styles: card (default), band, compact, minimal
* Uses your Mailchimp API key + Audience ID
* Can reuse keys from the official Mailchimp WordPress plugin

== Installation ==

1. Activate the plugin.
2. Settings → Newsletter — add API key and Audience ID (or connect the official Mailchimp plugin).
3. Add `[uucg_newsletter]` to any page.
